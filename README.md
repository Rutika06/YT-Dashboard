# 📊 YouTube Channel Analytics Dashboard

This project is a YouTube channel performance dashboard built using **Python**, **YouTube Data API**, **Pandas**, and **Seaborn**. It helps extract, analyze, and visualize key performance metrics from any YouTube channel.

---

## 🛠️ Technologies Used

- **Python 3.x**
- **Jupyter Notebook**
- **YouTube Data API v3**
- **Pandas**
- **Seaborn**
- **Matplotlib**

---

## 📌 Features

- 🔐 Authenticates and connects to the YouTube Data API.
- 📈 Extracts channel statistics (subscribers, views, total videos).
- 📋 Retrieves and processes video-level data such as views, likes, comments, etc.
- 📊 Visualizes top-performing videos using bar plots and time-series charts.
- 📅 Groups and analyzes upload trends by month to identify publishing patterns.
